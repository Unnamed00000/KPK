История версий KPK

Этот файл нужен для записи версий программы.
Каждый раз, когда в программу добавляется новое изменение, создается новая версия.
Под номером версии записывается, что именно было добавлено или исправлено.

Каждый номер версии является точкой возврата.
Чтобы восстановление работало правильно, каждая хорошая версия должна быть сохранена в Git как commit и tag.
Например: v1.4.27.

Как восстановить программу к хорошей версии:

1. Открыть папку проекта KPK.
2. Посмотреть доступные версии:
   git tag --list
3. Вернуться к нужной версии, например:
   git checkout v1.4.27

Важно: перед восстановлением лучше сохранить текущие изменения, если они нужны.

Формат записи:

vX.X.X - YYYY-MM-DD
- Что добавлено или изменено.
- Что исправлено.

v1.4.27 - 2026-08-12
- Для серии с несколькими промежутками времени добавлен отдельный итоговый блок под этими промежутками.
- Первая строка серии показывает только свое время, дополнительные строки показывают свое время, а нижний блок показывает общую сумму серии.
- Итоговый блок появляется только тогда, когда в серии есть дополнительные промежутки через зеленый плюс.

v1.4.26 - 2026-08-12
- Исправлен двойной подсчет времени, когда один промежуток работы попадает внутрь другого.
- Если дополнительное время серии пересекается с уже указанным временем, оно больше не увеличивает общий итог второй раз.
- Время в строках и в тексте для листка теперь показывает тот же расчет, что и общий итог дня.

v1.4.25 - 2026-08-12
- Добавлено автоматическое тире в номере серии после первых двух цифр, например 33-1.
- В обычной серии добавлен зеленый плюс для добавления дополнительного промежутка времени.
- Дополнительные промежутки времени сохраняются внутри этой же серии без повторения места и номера серии.
- Итог по серии теперь суммирует основное время и все дополнительные промежутки.
- В тексте для листка дополнительные промежутки показываются отдельными строками под той же серией.

v1.4.24 - 2026-08-12
- Добавлен понятный порядок ведения истории версий.
- Уточнено, что каждая новая версия является точкой возврата.
- Номер версии теперь должен записываться вместе со списком изменений.
- При следующем изменении программы нужно создавать новую версию и новую точку возврата.

v1.4.23 - 2026-08-12
- Добавлен режим рабочего периода Normal / Variable.
- Для Normal новые строки заканчиваются в 14:05, в пятницу в 14:00.
- Для Variable новые строки заканчиваются в 15:05, в пятницу в 15:00.
- Добавлен расчет накопленного времени Afspadsering.
- Добавлена кнопка + Afsp. для использования накопленного времени на неполный день.
- На календаре добавлены отметки N и V для режима дня.
- На календаре добавлены цветные точки: зеленая для заполненного дня, синяя для работы сверх выбранного режима, желтая для использованного Afspadsering.
- Добавлена кнопка ? с пояснением значков календаря.
- В тексте для листка рабочее время и период показываются одной строкой: Arbejdstid | Periode.
- Обновленная версия загружена на GitHub и Firebase.
